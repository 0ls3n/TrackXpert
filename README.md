# TrackXpert

TrackXpert is a cloud-based platform designed to help music producers manage, receive, and act on feedback for their tracks. With AI-powered task generation, users can efficiently organize their production workflow and turn feedback into actionable tasks, making it easier to enhance their music production process.

## Features

- **Track Upload**: Upload your audio tracks in multiple formats (e.g., MP3, WAV, FLAC).
- **Feedback Management**: Collect and organize feedback on your tracks from collaborators, clients, or listeners.
- **AI-Powered To-Do List**: Turn bookmarked feedback into actionable tasks, keeping your production organized.
- **Audio Preview**: Preview tracks directly on the platform after uploading.
- **Track Visibility Control**: Set your tracks to private or public for sharing with others.
- **Task Progress Tracking**: Keep track of feedback resolutions and actionable tasks.
- **Responsive Design**: Accessible from both desktop and mobile devices for a seamless user experience.

### Prerequisites

To access and use TrackXpert, you need:

- A web browser (Chrome, Firefox, Safari, etc.)
- An internet connection to access the cloud platform
- A free or premium account (depending on the feature set you need)

## Technologies Used

- **Frontend**: Blazor C#, HTML, TailwindCSS, JavaScript
- **Backend**: ASP.NET Core
- **Database**: SQL Server / MSSql
- **AI Integration**: Custom AI models for feedback task generation
